================================================================================
1. LE PROJET — C'EST QUOI
================================================================================

Serious game VR pour Meta Quest 2, Godot 4.7.2. Tu es schizophrène, tu as
oublié ta dose : fouille ton studio pour retrouver la pilule avant que la
jauge de folie n'atteigne 100 %. Le GDD verrouillé est dans ASSIMILE_GDD.md
(à la racine du dossier parent). Fragment 1 = le studio entier, jouable.

Design technique (imposé) :
- Renderer Compatibility (OpenGL / gl_compatibility) — LE renderer mobile
  officiellement recommandé pour Quest 2 dans Godot 4. Déjà réglé dans
  project.godot (desktop ET mobile).
- Graphismes "sympas mais pas gourmands" : primitives (box/sphere/cylinder),
  matériaux couleur unie, ZÉRO texture, baked-like via Environment (ambient +
  fog + glow + ACES), OmniLights sans ombres.
- Zéro physique coûteuse : pas de RigidBody, murs gérés par clamp de position.
- Commentaires et messages de code en français.

4. GAMEPLAY IMPLÉMENTÉ (GDD §4/§5)
================================================================================

- Stick gauche : déplacement constant 1,8 m/s, clampé aux murs (5,4 x 4 m).
- Stick droit : snap turn 45° (confort), anti-rebond 0,25 s.
- Gâchette index droite : rayon 3 m depuis la main → ouvrir tiroir/placard ou
  prendre la pilule. Le point central devient cyan quand quelque chose est
  visé. Haptique 0,25 s à chaque interaction.
- Folie : +1,4 pts/s tant que pas de dose. Vignette qui se referme, murs qui
  respirent (échelle), chat qui déraille ("IL EST DANS LA PIÈCE AVEC TOI"),
  puis game over "L'APPART T'A ASSIMILÉ" (gâchette/clic = recommencer).
- Dose : spawn aléatoire dans 1 des 4 conteneurs ou à plat sur un meuble,
  glow pulsant. Prendre une dose : sanity -55, montée ralentie à 0,7/s, nouvelle
  dose 2 s plus tard.
- Mimic : une tasse tremble (spawn aléatoire) ; si tu l'interagis, purge
  immédiate +6 folie. "Le faux est celui qui tremble."
- Fallback bureau (sans casque) : WASD + Q/E + F + clic souris, caméra à 1,7 m.
  Sert aux tests headless.

5. BUGS RENCONTRÉS → SOLUTIONS (ne pas les redécouvrir)
================================================================================

EXPORT / BUILD :
1. "Gradle build template not installed" → le preset doit pointer le template :
   gradle_build_directory="res://android"  (Godot AJOUTE lui-même /build ;
   si tu mets res://android/build il cherche android/build/build).
2. "Gradle build template version mismatch" → créer android/.build_version
   contenant EXACTEMENT "4.7.2.stable" (la vérification compare au version
   string officiel, sans suffixe).
3. "ETC2/ASTC required" → textures/vram_compression/import_etc2_astc=true
   dans project.godot.
4. Export sans VR → les clés du preset doivent être celles du plugin :
   xr_features/xr_mode=1 (OpenXR), screen/immersive_mode=true, etc. Un preset
   avec de mauvaises clés fait échouer l'export silencieusement.
5. Le build Gradle complet dépasse 570 s → timeout du terminal. L'APK est
   quand même écrit avant la fin ; vérifier avec ls, puis tuer le Godot restant.

CODE GODOT :
6. Vector3.BACKWARD n'existe PAS → Vector3.BACK (+Z, vers le joueur face à -Z).
7. Après ajout d'un class_name : relancer `Godot --headless --editor --quit`
   pour régénérer le cache des classes globales, sinon "Could not find type".
8. `log()` est déjà la fonction math globale (logarithme) → nommer ses
   méthodes autrement (log_line) ; et typer les vars qui les reçoivent.
9. *** ÉCRAN NOIR SUR QUEST 2 *** : OpenXR initialisé mais
   `get_viewport().use_xr = true` JAMAIS appelé → rien n'est soumis au
